# Clothing Website Project 👕🛍️

This is a simple and responsive clothing shopping website built with **HTML**, **TailwindCSS**, and a little **JavaScript** for mobile interactivity (toggle menu, etc). It is a personal project created as part of my learning journey in frontend development.
